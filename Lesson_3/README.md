###  Описание работы
В рамках данного домашнего задания были освоены базовые механизмы администрирования операционных систем семейства Linux. Практическая часть включает в себя мониторинг и управление процессами (исследование иерархии, фильтрация по пользователям, сортировка по ресурсоемкости), работу с фоновыми задачами, а также углубленное изучение встроенной справочной системы для быстрого поиска параметров команд.



###  Вывод
В ходе выполнения работы было освоено базовое администрирование и мониторинг процессов в Linux с помощью утилит `ps` и `jobs`. Приобретены навыки анализа дерева процессов, фильтрации по владельцу и ранжирования задач по потреблению оперативной памяти. Дополнительно были изучены возможности справочной системы `man` и поисковой утилиты `apropos`, что позволяет оперативно находить нужные ключи и команды без обращения к внешним источникам.
