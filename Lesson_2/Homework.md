### 1. Создание каталога work
```bash
mkdir work
```

### 2. Переход и pwd
```bash
cd work && pwd
```

### 3. Создание файла
```bash
touch file.txt
```

### 4. Заполнение файла (Гарри Поттер)

### 5. Переименование


### 6. Предложения со словом was


