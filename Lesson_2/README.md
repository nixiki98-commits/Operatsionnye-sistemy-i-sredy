###  Описание работы
В рамках данного домашнего задания были углублены навыки работы в интерфейсе командной строки (CLI) Linux. Практика охватывает управление файловой структурой (создание, перемещение, переименование), перенаправление потоков ввода-вывода (`>`), конвейеризацию команд, а также расширенную работу с текстовыми данными.


###  Вывод
В процессе выполнения работы были освоены операции по управлению жизненным циклом файлов и каталогов (`mkdir`, `touch`, `mv`). Закреплены навыки перенаправления стандартного вывода в файл и фильтрации текстового содержимого с помощью `grep`. Также на практике было изучено комбинирование нескольких команд в одну цепочку с помощью логического оператора `&&` и конвейера `|` для решения комплексных задач.
