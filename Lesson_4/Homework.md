## Задание 1. Host-Only адаптер

### 1.1. Создание адаптера
В VirtualBox активирован второй адаптер Host-Only. Сеть: 192.168.56.0/24, хост: 192.168.56.1.

### 1.2. Просмотр интерфейсов
```bash
ip address
```
lo — петля, enp0s3 — NAT, enp0s8 — Host-Only.

### 1.3. Назначение IP
```bash
ip address add 192.168.56.10/24 dev enp0s8
```

## Задание 2. Проверка связи

### 2.1. Ping себя
```bash
ping -c 4 192.168.56.10
```

### 2.2. Ping хоста
```bash
ping -c 4 192.168.56.1
```

### 2.3. Ping с хоста на гостевую
```bash
ping 192.168.56.10
```

## Вывод
Научился настраивать Host-Only сеть, работать с ip и ping. Host-Only удобна для связи хоста и ВМ без выхода в интернет.
