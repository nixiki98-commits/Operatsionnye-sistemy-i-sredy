## Задание 1. Подготовка и создание окон

### 1.1. Установка tmux
```bash
apt install -y tmux
```

### 1.2. Запуск
```bash
tmux
```
Окно tmux имеет строку статуса и поддерживает несколько окон/панелей в одной сессии.

### 1.3. Новое окно
Ctrl+B, C — создано второе окно.

### 1.4. Переименование и vim
Ctrl+B, , — переименовано в Text, запущен vim.

## Задание 2. Разные окна

### 2.1. Скрипт Python
Скрипт timer.py пишет секунды в test.txt.

### 2.2. Запуск и watch
```bash
python3 timer.py &
watch -n 1 ls -l test.txt
```

## Задание 3. Разделение окон

### 3.1. Горизонтальное разделение
Ctrl+B, % — установка fastfetch в правой панели.

### 3.2. Запуск fastfetch
```bash
fastfetch
```

### 3.3. Вертикальное разделение
Ctrl+B, " — деление по вертикали. Закрытие областей через exit.

## Вывод
tmux позволяет работать с несколькими окнами и панелями. Сессия сохраняется при отключении.
