###  Описание работы
В рамках данного домашнего задания были отработаны базовые навыки работы в CLI (интерфейсе командной строки) операционных систем на базе Linux. На практике применены утилиты для поиска, фильтрации, сортировки и просмотра содержимого файлов.


###  Вывод
В процессе выполнения работы были освоены базовые команды Linux для работы с файловой системой и текстом (`ls`, `cat`, `grep`, `find`). Приобретены навыки фильтрации вывода, поиска объектов по имени и владельцу, а также комбинирования утилит через конвейеры (pipe) и параметр `-exec`. Полученные знания формируют фундамент для дальнейшего администрирования ОС.
