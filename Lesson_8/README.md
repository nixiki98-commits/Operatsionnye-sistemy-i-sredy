###  Описание работы
В рамках данного домашнего задания были изучены принципы процедурного программирования в командной оболочке Bash. Практическая часть включает в себя создание пользовательских функций, обработку входящих аргументов, управление локальными переменными, динамическое перенаправление потоков данных, использование команды `eval` для косвенного обращения к переменным, а также организацию интерактивных циклов с обработкой состояния EOF (`Ctrl + D`).


###  Вывод
В ходе выполнения работы были успешно освоены механизмы создания модульного кода в Bash с использованием функций, изолированных локальных переменных (`local`) и позиционных параметров (`$1`, `$2`). Закреплены навыки гибкого перенаправления вывода в различные потоки (стандартный вывод, поток ошибок, текстовые файлы) и динамического вычисления команд с помощью `eval`. Отработаны сценарии создания интерактивных утилит, корректно завершающих работу при наступлении события конца файла (EOF).
